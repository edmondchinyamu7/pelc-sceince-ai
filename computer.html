1. JavaScript Basics

JavaScript lets a webpage respond to clicks, process information and update content.

Variables

A variable stores a value. Use const for a value that won't be reassigned and let for one that may change.

const company = "PELC";
let score = 0;

score = score + 1;

console.log(company);
console.log(score);

Functions

A function groups instructions so you can run them when needed.

function greet(name) {
  return "Hello, " + name + "!";
}

console.log(greet("Student"));

Conditions

const mark = 75;

if (mark >= 50) {
  console.log("Pass");
} else {
  console.log("Try again");
}

4. How Websites Work

HTML

Creates the structure and content of the page.

  () => alert("Hello!")
